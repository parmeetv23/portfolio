# Prototype typefaces

Self-hosted Latin subsets downloaded from Google Fonts on 2026-10-16. These files
are used only by the isolated, development-only design-lab layout.

- Newsreader: Production Type, SIL Open Font License 1.1.
  https://github.com/productiontype/Newsreader
- Public Sans: USWDS, SIL Open Font License 1.1.
  https://github.com/uswds/public-sans
- Bricolage Grotesque: Mathieu Triay / Atelier Triay, SIL Open Font License 1.1.
  https://github.com/ateliertriay/bricolage
