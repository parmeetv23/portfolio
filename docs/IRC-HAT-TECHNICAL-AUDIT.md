## Material disagreements requiring owner context

1. **Ordering and consistency:** report pp. 13–17 describe vector timestamps, eventual P-RAM, and sequential registry consistency. Current message classes/logs use wall-clock timestamps and live receive order; ACK-before-apply, untracked updates, and concurrent workers contradict treating those guarantees as established for this revision. The report's design rationale is retained: asynchronous chat propagation versus tighter registration coordination. Neither a formal guarantee nor its impossibility in another revision is inferred.
2. **Recovery revision:** the report describes full-log restoration and fresh history after reconnect. Current source has the separate uninitialized full-log path and persistent client `isRegistered` guard described above. Was the final demonstration built from a different revision, or were these paths changed after demonstration?
3. **Addressing failure detector:** report p. 19 describes RTT-driven timeout failure action. `PingManager:180–222` measures TCP connection completion, computes an estimate, but its removal action is commented out; its primary branch sleeps. The demonstrated election begins with control-connection loss/primary removal. No complete adaptive-timeout pipeline is implied.
4. **Client retransmission:** report p. 17/original Page 8 describe resending unacknowledged messages; source only identifies send-exception requeue. Confirm whether a separate resend implementation existed in the demonstrated revision.
5. **Primary discovery:** report p. 17 describes backup addresses, but its final challenges discussion on p. 20 explicitly says discovery of an elected primary remains unfinished; clients configure one host and chat primary updates are not adopted in this source. Keep that scope explicit and never draw client rerouting to a newly elected addressing primary.

These conclusions distinguish implementation contradictions from lack of runtime verification. The report's qualitative account of a working multi-process chat application is not rejected because the supporting investigation did not execute it. No measured benchmark results are present in the final report; none are introduced.
